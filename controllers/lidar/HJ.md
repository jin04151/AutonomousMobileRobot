# B 담당 알고리즘

체크는 코드 구현 여부이며, 실제 Webots 센서·주행 검증은 별도로 필요함.

## 3. Exploration — 탐색 목표 선택

1. [x] Unknown에 4방향으로 인접한 Free 셀을 Frontier로 찾고 BFS로 그룹화.
2. [x] 안전한 Free 영역에서 BFS를 수행해 도달 가능한 후보와 이동거리 계산.
3. [x] 후보별 점수 계산 후 실제 후보 셀을 목표로 선택.
   - 예상 관측량: 주변 Unknown 비율이 높으면 가점. 벽 차폐는 아직 미반영.
   - 이동거리: 안전 영역을 따라 이동할 거리가 길수록 감점.
   - 회전량: 경로의 첫 진행 방향으로 많이 돌아야 하면 감점.
   - 재방문: 도착했던 목표 주변을 감점하고 시간에 따라 감소.
4. [x] 목표 유지: 새 후보의 점수가 충분히 좋아질 때 변경. 도착·차단·무효 시 재선택.
   - 방문 이력·목표 유지는 `FrontierSelector`를 연결해야 적용됨.
   - `choose_goal()`만 호출하면 관측량·거리·회전 점수만 사용.
5. 후보가 없으면 `None`. 전체 임무 완료를 의미하지 않음.

## 4. Object Detection — 목표물 검출

1. [x] Webots BGRA 이미지를 BGR NumPy 배열로 변환.
2. [x] 검출 결과를 `Detection(label, bbox, confidence)`로 표현.
3. [ ] 목표물 사양에 맞는 OpenCV 규칙 또는 검출 모델 구현.
   - 현재 `detect_targets()`는 빈 리스트를 반환함.

## 5. Target Localization — 물체 위치 추정

1. [x] 보정 행렬로 LiDAR 점을 카메라 영상에 투영.
2. [x] 카메라 앞쪽·영상 내부·검출 상자 안의 점만 추출.
3. [x] 깊이 차로 점들을 그룹화. 점 부족·여러 거리군·과도한 깊이 폭이면 `None`.
4. [x] 단일 점군의 대표 위치를 로봇 좌표에서 pose와 같은 지도 좌표로 변환.
5. [x] 카메라·LiDAR 점·pose의 시각 차이가 허용 범위를 벗어나면 거부.
6. [ ] 실제 영상과 LiDAR 정합 확인 및 이동 중 점별 시각 보정.

반환값은 **물체 표면의 대표 위치**이며 물체 중심이나 로봇의 안전 접근 목표가 아님.
상자 안에 배경벽만 잡힌 경우는 아직 구별하지 못함.

## 목표 목록·중복 관리

1. [x] 같은 종류·거리 범위의 기존 목표와 프레임별 일대일 대응.
2. [x] 대응이 명확하면 같은 ID의 위치·마지막 관측 시각 갱신.
3. [x] 기존 후보가 없으면 새 ID 등록. 여러 후보·중복 대응·가까운 새 관측은 보류.
4. [x] 발견 → 접근 중 → 방문 완료 상태 관리. 접근 취소 시 발견 상태로 복귀.
5. [x] 방문 완료는 외부 확인으로만 변경하고 재관측에도 유지.

거리 기준은 실제 위치 오차를 보고 설정해야 하며, 종류·거리만으로 물체 신원을 보장하지는 못함.
**안전 접근 목표와 방문 완료 조건은 C·통합 담당과 연결할 부분임.**

## 메인 연결

- 탐색은 `FrontierSelector` 사용. 유효한 목표를 유지하고 무효 목표는 재선택.
- BGR 변환 → 다중 검출 → 위치 추정 → 목표 목록 갱신 연결. 보정·대응 기준·카메라 시각·중복 거리는 확인 후 메인 설정에 입력.
- 설정 전에는 위치 추정을 대기하고 탐색 수행. 물체 방문·복귀는 아직 미연결.
- C의 호출·재계획·주행 상태 처리는 pull한 코드 유지. B는 기존 형식의 `(x,y)` 또는 `None`을 goal로 전달.
- 도착·차단·계획 실패 결과의 B 피드백은 미연결. 목표에 도착한 뒤 다음 탐색으로 넘기는 처리는 통합 담당과 연결 필요.
- 탐색 진단은 1초 로그, Frontier·목표·로봇 표시는 5초/종료 시 `map.png` 덮어쓰기.
